# my_money

💰 My Money – Personal Finance Tracker

A modern, minimal Flutter-based personal finance tracking app that helps users manage income, expenses, and gain insights into their spending behavior.

🚀 Features

📊 Dashboard (Home)
Displays:
Current Balance
Total Income
Total Expenses
Shows recent transactions
Includes weekly spending bar chart
Clean and intuitive UI

📈 Insights
Weekly analytics
This Week vs Last Week (Income & Expenses)
Percentage change indicators
Category-wise spending (Pie Chart)
Smart insights like:
Top spending category
Spending trends

📜 Transactions
Add income/expense entries with:
Amount
Category (Food, Travel, Shopping, Bills)
Date
Optional note
View all transactions
Long press to delete
UX hint: tap to reveal delete instruction

📊 Visualizations
Bar Chart
Daily spending (Mon–Sun)
Pie Chart
Category-wise expense distribution
Consistent color mapping (legend + chart)

💾 Local Storage
Uses Hive (NoSQL local database)
Fast, lightweight, offline-first
No backend dependency

🧱 Tech Stack
Flutter – UI framework
Dart – Programming language
Provider – State management
Hive – Local database
fl_chart – Data visualization
google_nav_bar – Bottom navigation UI

🧠 Key Concepts Implemented
State management using Provider
Clean UI component separation
Dynamic data aggregation (weekly, category-based)
Responsive layouts
Custom reusable widgets
Navigation using indexed state (no route push for tabs)
